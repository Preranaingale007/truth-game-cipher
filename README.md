# Logic Gate

Create a polished cinematic educational web game called:

THE LOGIC GAMES

TAGLINE:

"Think carefully. Every answer matters."

IMPORTANT:

This is an original survival-puzzle game inspired by the tension,

mystery and visual atmosphere of high-stakes elimination game shows.

Do NOT copy any existing TV show's characters, costumes, symbols,

logos, music, scenes, dialogue, masks, uniforms, or copyrighted

visual identity.

Create completely original characters, symbols, environments,

storytelling and UI.

The game must be a university-level Discrete Mathematics project.

The gameplay combines:

SURVIVAL GAME ATMOSPHERE

+

ESCAPE ROOM

+

DISCRETE MATHEMATICS

+

CINEMATIC STORYTELLING

The player is identified as PLAYER 047.

GAME STRUCTURE

There are FOUR major games.

Each game contains multiple mathematical challenges.

The player must successfully solve enough challenges to unlock the

exit.

Each game should have its own environment and atmosphere.

--------------------------------------------------

GAME 01 — THE FIRST DOOR

TOPIC:

Propositions and Logical Operators

Environment:

A huge empty chamber containing four enormous locked doors.

Each door has a glowing mathematical symbol.

A countdown appears above the room.

The Host explains:

"Every door has a statement."

"Only one statement is true."

The player must solve propositional logic questions.

Include:

- propositions

- AND

- OR

- NOT

- implication

- simple logical expressions

At least 6 questions.

Each correct answer activates part of the room.

After enough correct answers:

The correct door glows.

The locks mechanically disengage.

The door opens.

Create a dramatic transition.

--------------------------------------------------

GAME 02 — THE TRUTH ROOM

TOPIC:

Truth Tables

Environment:

A huge control room.

There are dozens of screens.

Each screen displays portions of truth tables.

The player must determine which system is logically valid.

Include:

- truth values

- compound propositions

- truth tables

- tautology

- contradiction

At least 6 questions.

Wrong answers:

- countdown decreases faster

- warning lights activate

- surveillance cameras turn toward the player

- screen briefly glitches

- threat level increases

Correct answers:

- control panels activate

- lights stabilize

- countdown briefly pauses

- next section unlocks

--------------------------------------------------

GAME 03 — THE MIRROR CHAMBER

TOPIC:

Logical Equivalence

Environment:

A massive mirrored room.

There are multiple doors.

Each door contains a logical expression.

The player must determine which expressions are equivalent.

Use:

- De Morgan's Laws

- implication equivalence

- logical equivalence

- tautology

- contradiction

Create visual matching puzzles.

For example:

Expression A

and

Expression B

appear on opposite walls.

The player selects whether they are equivalent.

Correct answers cause the environment to change.

Walls illuminate.

Doors rearrange.

The mirrors reveal hidden symbols.

Create visually impressive transitions.

--------------------------------------------------

GAME 04 — THE FINAL JUDGMENT

TOPIC:

Rules of Inference

Environment:

A massive central arena.

The Host appears on the screen.

This is the hardest game.

Use:

- Modus Ponens

- Modus Tollens

- valid inference

- invalid inference

- multi-step reasoning

At least 8 questions.

Each answer affects the final countdown.

The player must solve the entire sequence before the timer reaches

zero.

--------------------------------------------------

THREAT SYSTEM

Create a non-graphic psychological pressure system.

Do not show violence.

Instead, mistakes increase:

THREAT LEVEL

Level 1:

Normal environment.

Level 2:

Lights flicker.

Level 3:

Warning lights activate.

Level 4:

Surveillance cameras become more active.

Level 5:

The Host interrupts the game.

Display:

"PLAYER 047."

"You are running out of chances."

The game should create tension without graphic violence.

--------------------------------------------------

THE HOST

Create an original mysterious Host.

The Host should appear only occasionally.

Never reveal their full identity.

Use:

- silhouette

- distorted video feed

- voice-like text

- giant screens

- surveillance monitors

The Host should give instructions and react to progress.

Example:

After several correct answers:

"Interesting."

After a wrong answer:

"That was careless."

After multiple mistakes:

"Perhaps you are not ready."

Do not make the Host directly threaten physical harm.

--------------------------------------------------

COUNTDOWN

Every major challenge should have a visible countdown.

Use an animated digital timer.

When time becomes low:

- digits pulse

- warning lights activate

- UI shakes slightly

- background sound intensity increases

- screen displays WARNING

Do not make the countdown impossible.

The mathematical challenge must remain the focus.

--------------------------------------------------

Create:

- mechanical lock animations

- screen glitches

- camera movement

- lighting changes

- particle effects

- button hover effects

- question transitions

- answer feedback

- countdown animations

Then provide:

WHY?

Q = FALSE

P ∧ Q

Therefore:

FALSE

Logical AND

↓

RULE

↓

CONCLUSION

This is essential because the project must demonstrate

Discrete Mathematics rather than being only a quiz.
